# Manavizha Homepage Redesign

## Objective

Redesign the homepage hero section to feel premium, trustworthy, and emotionally engaging.

The current design feels:

* AI-generated
* Too generic
* Too much empty space
* Weak emotional connection
* Lacking visual storytelling

The redesign should feel closer to a premium matrimonial experience.

---

# Design Direction

Use the attached reference image as inspiration.

Do NOT copy it pixel-for-pixel.

Instead replicate the design principles.

---

# What Makes The Reference Better

## 1. Emotional Storytelling

The current homepage uses text and a process card.

The reference uses a happy couple image.

This immediately communicates:

* Marriage
* Love
* Family
* Trust
* Success

Users understand the purpose instantly.

---

## 2. Strong Visual Hierarchy

Priority order:

1. Headline
2. Couple image
3. CTA
4. Trust indicators
5. Process explanation

Current page gives equal visual weight to everything.

The redesign should have clear hierarchy.

---

## 3. Premium Typography

Use elegant typography.

Requirements:

* Large hero headline
* Strong contrast
* Comfortable line heights
* Fewer font weights

Avoid looking like a startup landing page.

---

## 4. Trust-Focused Design

A matrimonial platform is a trust business.

Add:

* Verified profile indicators
* Family trust metrics
* Success stories count
* Safety messaging

Trust should be visible above the fold.

---

## 5. Better CTA Strategy

Primary CTA:

"Start Your Journey"

Secondary CTA:

"Browse Profiles"

The primary CTA should dominate visually.

---

# Brand Colors

DO NOT use the colors from the reference image.

Use Manavizha colors only.

Extract colors from:

* Logo
* Existing brand palette

Maintain brand consistency.

# Couple Image Section

Use:

* Elegant Indian wedding imagery
* Soft edges
* Premium framing
* Subtle depth

Avoid:

* Stock-photo appearance
* Harsh shadows
* Generic placeholders

---

# Visual Style

Preferred:

* Warm
* Elegant
* Premium
* Calm
* Human

Avoid:

* Glassmorphism
* Excessive gradients
* Neon effects
* Crypto aesthetics
* SaaS dashboard style

---

# Cursor Workflow

Before coding:

1. Analyze current homepage.
2. Explain weaknesses.
3. Propose redesign.
4. Create wireframe.
5. Implement.
6. Critique implementation.
7. Suggest improvements.

Do not immediately generate code.
Think like a senior product designer first.
